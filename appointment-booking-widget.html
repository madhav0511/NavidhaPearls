Developer Integration Documentation:

  • Target Calendar ID: navidha.pearls@gmail.com
  • Conflict Calculation: Evaluates gapi.client.calendar.freebusy.query. For every booked meeting [start, end], any slot starting between start - slotDuration and end + bufferMinutes (10m) is disqualified.
  • Buffer Rule: If an existing appointment runs from 10:00 AM – 10:30 AM, the earliest next available slot must start at 10:40 AM or later.
  • Modular Core Functions: fetchBusySlots(date), generateTimeSlots(date, slotDuration, bufferMinutes), renderTimeSlots(availableSlots, showGrayedOut).
